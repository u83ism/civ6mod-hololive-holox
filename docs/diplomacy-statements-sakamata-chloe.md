# 沙花叉クロヱ 外交台詞たたき台

外交交渉画面の台詞(`LOC_DIPLO_*`)を実装する前の検討資料。キャラクター像の根拠は`docs/character-sakamata-chloe-personality.md`、タグの意味(誰が何をした時に出るか)は`.claude/skills/implement-diplomacy-statements/references/diplomacy-statement-schema.md`を参照。**2026-09-27、採用した台詞を`Text/ja_JP/Text.xml`に実装した(日本語のみ)。表中の「不採用の案」は記録として残している。**

タグは全て`LOC_DIPLO_<場面>_LEADER_HOLOX_SAKAMATA_CHLOE_ANY`の形になる(下の表では`<場面>`部分のみ記載)。

## 1. 兄弟Mod(一条莉々華)の実装分析

`civ6mod-hololive-regloss`で2026-09-21〜22に実装されたもの。

### 実装範囲

- `LOC_DIPLO_*`は`Text/<言語>/Text.xml`に計80行(アジェンダ理由文・関係値補正の表示名4行を含む。場面の台詞としては76タグ)。ja_JP/en_US/zh_Hans_CN/zh_Hant_HKの4言語すべてに同数を用意
- 別ファイル化はせず、他のLOCテキストと同じ`Text.xml`内にカテゴリごとの空行区切りで並べている
- スキーマ一覧(`references/diplomacy-statement-schema.md`)にある場面は全部埋めている。バニラの主要リーダー(トラヤヌス・ガンディー・クレオパトラ)が個別に用意しているのは33タグ程度で、残りは汎用フォールバックに任せているので、莉々華はバニラより手厚い

### 実装の進め方(コミット履歴より)

1. パーソナリティ調査メモを作る(`docs/character-ichijou-ririka-personality.md`)
2. カテゴリ単位で4コミットに分けて実装: 初対面・宣戦布告・敗北・友好・同盟・非難・アジェンダ示唆 → 使節団・大使館・国境開放 → 取引・講和・要求 → 個別警告4種
3. 英訳を別エージェントで逆翻訳して、ニュアンスのズレを修正(例: "officially friends"が「友好宣言」の硬さを呼び戻していたので"friends"に修正)
4. 実機で見た後、GREETING/FIRST_MEETを配信者本人の決め台詞ベース(「こんりり〜」「かわいい！ポジティブ！ジーニアス！」)に差し替え。他言語では語呂合わせを訳さず"Konriri"とラテン文字で残した

### 書き方の傾向

- タメ口・短文中心(1〜2文)。バニラのリーダーも1〜2文なので、画面に収まる長さの目安になる
- 本体の台詞は「ねえ、〜」で始まるものが13件あり、やや単調
- 警告に応じてもらった時の反応(`HUMAN_RESPONSE_POSITIVE`)は4テーマ中3つが「ありがと」だけ。ここは表示機会が少ないので、割り切って短くしている
- 女社長の設定を場面に合わせて言い換えている(使節団=「うちのスタッフ」、大使館=「駐在員」、都市=「支店」)。**クロヱでは「掃除屋」「シャチの群れ」が同じ役割の言い換え元になる**
- 性格(平和主義)がアジェンダ・宣戦布告の台詞と一貫している(「ほんとはこんなことしたくないんだけど」)

### クロヱの実装に持ち込むこと・変えること

- 持ち込む: カテゴリ単位のコミット分割、決め台詞ベースのGREETING/FIRST_MEET、逆翻訳チェック、1〜2文という長さ
- 変える: 一人称「沙花叉」を徹底する。本体台詞の書き出しを「ねえ」で揃えない(クロヱの口癖は文末の「ね！」の方)。決め台詞(ばっくばっくばく〜ん/ぽえぽえぽえ〜/お掃除)は使い回すと安っぽくなるので、下の「決め台詞の使用予算」で管理する

## 2. トーン設計

- 一人称は必ず「沙花叉」。相手は「そっち」
- 基本は生意気な後輩のタメ口。煽る時・ツッコむ時にときどき丁寧語(「〜なんですけど？」「〜ですか？」)を混ぜる
- 「掃除」は**始末**(仕事)の意味で使い、**部屋の掃除・風呂が苦手**というずぼらさを友好的な場面のオチに使う。物騒さ(戦争・警告)とゆるさ(友好・取引)の振れ幅がクロヱらしさの本体
- 拒絶された時は一度素直に傷ついてから強がる。「わからされる」側の可愛げを残す
- 同盟・要求の受諾など、面倒を見る場面では長女のお姉ちゃん気質(「守られるより守りたい派」)を出す
- 下ネタ・他のホロメンの名前は使わない

### 決め台詞の使用予算

同じ決め台詞が何度も出ると安っぽくなるため、登場回数を絞る。下の案での配置:

| 決め台詞 | 使う場面 |
| --- | --- |
| ばっくばっくばく〜ん | GREETING、FIRST_MEET(自己紹介ママ)、DECLARE_WAR_FROM_AI(鬨の声) |
| ぽえぽえぽえ〜 | 取引拒否(`MAKE_DEAL_AI_REFUSE_DEAL`)、入植警告への反発 |
| お掃除/掃除屋 | 宣戦布告・講和決裂・警告系。多めになるので、実装時に本人の目で間引く |
| ねぇ↑えぇ↓ | 非難、大使館を断られた時、取引を断られた時(3回は多いので採用時に絞る) |
| やだやだやだ | 国境開放を断る、要求を断る(同上、どちらか1つに絞るのも可) |

## 3. 重要度

「表示される頻度」と「キャラクター性の見せ場としての大きさ」で4段階に分けた。

| 重要度 | 基準 | 場面 |
| --- | --- | --- |
| **S** | ほぼ全プレイで必ず見る/印象に残る | GREETING、FIRST_MEET、DECLARE_WAR(2種)、DEFEAT(2種)、DENOUNCE(2種)、DECLARE_FRIEND_FROM_AI、KUDO_EXIT、WARNING_EXIT、MAKE_PEACE_FROM_AI |
| **A** | バニラの主要リーダーが個別に用意している標準セット、または取引のように頻繁に見る場面 | FIRST_MEETの派生3種、友好宣言への返答4種、MAKE_ALLIANCE_FROM_AI、使節団・国境開放の提案/返答、取引5種、講和の受諾/拒否、TOO_MANY_TROOPS_NEAR_MEの本体 |
| **B** | バニラでは汎用フォールバック任せだが、莉々華では実装した場面 | 同盟への返答4種、大使館5種、講和案への反応2種、要求4種、DONT_SETTLE_NEAR_MEの本体 |
| **C** | 発生頻度が低い/短い一言で済む | 個別警告の応答類(5テーマ×最大4種)、布教・遺物・スパイの警告本体3種 |

補足:

- Aの「バニラ標準セット」は、トラヤヌス・ガンディー・クレオパトラの3人が共通して個別タグを持っている範囲(`Base/Assets/Text/en_US/DiplomacyStatements_*_Text.xml`、2026-09-26確認)。個別警告5テーマの中で、バニラの主要リーダーが本体を個別に持っているのは`TOO_MANY_TROOPS_NEAR_ME`だけだった
- 最低限の品質で出すならS+A(約35タグ)、莉々華と同等の網羅度にするならB・Cまで(76タグ)
- **アジェンダの理由文(`LOC_DIPLO_KUDO/WARNING_LEADER_ANY_REASON_AGENDA_*`)とDIPLO_MODIFIERの表示名は、クロヱのユニークアジェンダ自体がまだ設計されていないので今回の対象外**。アジェンダを決めた後に書く(重要度はS相当)
