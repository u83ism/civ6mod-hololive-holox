## 都市名(2026-09-30決定)

シャチを観察できる海域名から21件(`XML/Civilizations.xml`の`CityNames`)。首都は羅臼(`CapitalName`)、以降は`RandomCityNameDepth="10"`(公式の通常文明と同じ値)で、先頭10件(羅臼・知床・根室・カムチャツカ・ジョンストン海峡・ロブソン・バイト・ティスフィヨルド・バルデス・ジブラルタル・標津)の中からランダム、11件目以降は載せた順。公式の通常文明は30〜40件・深度10(2026-09-30にゲーム本体で確認)。`tools/loc-lookup`で公式の都市名(`LOC_CITY_NAME_*`)と日英の両方で照合し、かぶったトロムソ(Tromsø)とサン・フアン(San Juan)は外した。

- 日本語・英語: 一般的な表記。
- **中国語(簡体字・繁体字)は全件、公式表記の裏取りをしていない**。慣用の音訳を当てただけで、特に「罗布森湾」「蒂斯峡湾」「谢尔沃伊」「格伦达尔峡湾」は定訳が確認できていない。実機で表示を確認するときに合わせて見直す。
- 当初はオルカベイ(旧首都名)・サカマタ・シャチホコ・グランパスも入れていたが、海域名に統一するため外した(2026-09-30。「脈絡がない」という本人判断)。

### かざま隊の都市名(2026-10-02決定)

日本百名山から30山(`XML/KazamaTai.xml`の`CityNames`)。「日本の百名山」を使うことと、首都を富士山にすることは本人の決定。仕組みは上と同じで、首都は富士山(`CapitalName`、`CityNames`の先頭にも入れた)、`RandomCityNameDepth="10"`。当初の仮の首都名「山里」は削除した。

- 日本百名山は深田久弥が1964年に選んだ100山の選定で、**順位ではない**。先頭10件(富士山・立山・白山・槍ヶ岳・北岳・阿蘇山・大山・御嶽山・羊蹄山・筑波山)を有名どころにしたのはAIの並びで、百名山自体の序列ではない。
- 30山という件数と、どの山を選ぶかはAIの案(公式の通常文明が30〜40件のため)。全100山にする・入れ替えるかは未決。
- 公式の都市名との重複は`tools/loc-lookup`で山名を絞って照合したが、出力が途中で切れて末尾まで見ていない。
- 英語・中国語は2026-10-03に仮案を全削除して決め直した(30件の対訳は`Text/`の各言語を参照)。
  - 英語: 英語版ウィキペディア「100 Famous Japanese Mountains」の表記をそのまま使う(本人が「Mount ○○」形式を選択)。公式の自然遺産(Mount Everest・Mount Kilimanjaro・Mount Roraima・Mount Vesuvius)が「Mount」付きのため。ウィキペディアが「Mount」を付けないDaisen・Daisetsuzan・Hakkoda・Yatsugatakeは付けない。対抗案は「Mount」を外す案(Fuji, Aso…)と日本語名全体のヘボン式(Fujisan…)。
  - 中国語: 中国語版ウィキペディアの記事見出しまたは「日本百名山」一覧の表記(**公式表記ではない**)。簡体字と繁体字で字が違うのは槍ヶ岳(枪岳/槍岳)・御嶽山(御岳山/御嶽山)・石鎚山(石锤山/石鎚山)・男体山(男体山/男體山)・剣山(剑山/劍山)など。蔵王山は記事見出しの「藏王连峰/連峰」ではなく一覧の「藏王山」、北岳の繁体字は記事本文の「北嶽」ではなく見出しの「北岳」を選んだ(いずれもAIの判断)。
  - 公式の都市名(バニラ・DLCの`LOC_CITY_NAME_*`)との重複は、英語・簡体字・繁体字とも無いことを確認した(2026-10-04)。

## 台詞・口癖の方針(2026-09-30決定、英語版で適用済み)

外交台詞など、口癖・固有語を含む文の扱い。中国語版でも同じ型を適用する(表記は言語ごとに決める)。

| 型 | 方針 | 例(英語) |
|---|---|---|
| 意味のない鳴き声・挨拶 | 訳さず音をローマ字で残し、全台詞で表記を固定する | ばっくばっくばく〜ん → Bakku bakku baku~n |
| 意味のある固有語 | 意味で訳す(公式の各言語表記があればそれを使う) | 掃除屋でインターン → cleaner-slash-intern / 秘密結社holoX → Secret Society holoX |
| 一人称「沙花叉」 | 三人称の自称を残す。自己紹介のように「I」が自然な文は「I」にする | Chloe hasn't even sung enough yet! |
| 口調・語尾・イントネーションの口癖 | 逐語訳せず、その言語で自然なキャラ付けに書き直す | ねぇ↑えぇ↓ → Heeey… / もぉ〜やだぁ〜 → Noooo, come on… |
| 「お掃除」(掃除=始末の二重の意味) | 「cleanup」等、両方の意味が通じる語で残す | お掃除対象 → cleanup list |
| 中国語の二人称 | 簡体字・繁体字とも「你」で統一する。公式のTrait説明は簡体字「您」・繁体字「你」が標準だが、公式の外交台詞は簡体字でも敵対・感情的な場面で「你」を使っており、外交相手にタメ口で話すキャラに「您」は合わないため(2026-09-30決定) | 你(您は使わない) |
| ゲーム用語が混ざる台詞 | `.claude/rules/game-terms.md`に従い公式訳を引く | delegation / embassy / open borders |
