# キャラクター名・人名の表記

対象はコード変数名ではなく、コミットメッセージ・チャットでの説明文・ドキュメント・XMLコメント等、文章中に登場するキャラクター名・人名全般。

- キャラクター名(特に当て字・変則読みを含む名前、例: 沙花叉クロヱ)を文章に書く前に、必ず`Text/ja_JP/Text.xml`の`LOC_LEADER_*_NAME`/`LOC_CIVILIZATION_*_NAME`等、リポジトリ内の確定済み表記を検索して確認する。`LEADER_HOLOX_SAKAMATA_CHLOE`のようなローマ字の識別子から漢字表記を音や語感で類推しない(類推すると「沙花叉クロヱ」を「坂本チョコ」のような、もっともらしいが実在しない当て字に書き換えてしまう)。
- 確認した表記は記憶で打ち直さず、確認元(grep結果・Read結果)の文字列をそのままコピーして使う。手打ちでの再現は文字化け・字形の取り違え(例: 「ヱ」を「ヴ」と書く)の原因になる。
- コミットメッセージ・PR説明文等、後から訂正しづらい/訂正コストが高い箇所にキャラクター名・人名を書く場合は、書く前に上記の確認を省略しない。
- 表記が確認できない・複数の資料で表記が割れている場合は、断定せず本人に確認する(`persona/README.md`の「視覚・見た目情報の扱い」と同種の注意: もっともらしい類型で埋めて自信ありげに断定しない)。
