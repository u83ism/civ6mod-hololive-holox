# Civ6の公式用語

対象はゲーム内テキスト(LOC)に限らず、チャットでの説明・`docs/`・コミットメッセージ・Steam説明文等、**文章中にCiv6本体の用語を書くときすべて**。Yield(文化力・観光力等)・建造物・区域・資源・傑作の種類・技術・社会制度・政策・ゲームモード固有語などが該当する。

- **記憶や直訳で書かない**。Civ6本体の翻訳ファイルが公式の対訳辞典そのものなので、書く前にそこで確認する: `tools/loc-lookup`で`npm run lookup -- <LOCタグの正規表現>`(例: `"^LOC_GREAT_WORK_OBJECT_"`)、タグが分からなければ`npm run lookup -- --text <文字列> [--lang ja_JP] [<タグの正規表現>]`で逆引きする。en_US/ja_JP/zh_Hans_CN/zh_Hant_HKがまとめて出る
  - 記憶で書いて誤った実例(2026-09-27): `GREATWORKOBJECT_RELIC`を「聖遺物」(正式は「遺物」)、`GREATWORKOBJECT_WRITING`を「著作」(正式は「書物」)と書いた
- **言語ごとに個別に確認する**。ある言語の訳から別の言語の訳を類推しない。簡体字と繁体字も字体変換の関係とは限らない(例: 遺物は簡体字「遗物」・繁体字「遺跡」)
- 確認した訳語は、確認元の出力をそのままコピーして使う(打ち直さない)
- `idea`リポジトリの用語対訳CSV(`map-terms` Skill管轄)は、ゲーム本体を引けない場面向けの早引きという位置づけ。Civ6ではゲーム本体の翻訳ファイルを優先し、CSVと食い違ったらゲーム本体が正
- このMod自体のキャラクター名・人名は`character-names.md`、ゲーム内テキストの文体・言い回し(用語より大きい単位)は`write-game-text` Skill
