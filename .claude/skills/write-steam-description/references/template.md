hololive ReGLOSSをモチーフにした新しい文明を追加するMODです。

【開発中です】
現在実装済みなのは一条莉々華(一条コーポレーション)のみです。バグが残っている可能性があります。気づいた点があればコメントで教えてください。

【対応言語】
日本語・英語・簡体字・繁体字に対応しています。開発者は日本語しか使えず、それ以外のテキストはClaude(AI)の助けを借りて翻訳しており、不自然な表現や誤りが含まれている可能性があります。指摘は歓迎します。

【バランスについて】
HktkNban氏のHololive JP Mod、Neox氏のHololive EN/ID Modと混ぜて使うことを想定しているため、単体で見るとやや強め(オーバーパワー気味)の調整にしています。MODなし環境で強いとされる指導者が平均～やや弱いレベルになります。
