[b]現在実装済みなのは沙花叉クロヱ(シャチの群れ)のみです。[/b]

[h2]🌐 対応言語[/h2]
日本語・英語・簡体字・繁体字に対応しています。開発者は日本語しか使えず、それ以外のテキストはClaude(AI)の助けを借りて翻訳しており、不自然な表現や誤りが含まれている可能性があります。指摘は歓迎します。

[h2]⚖️ バランスについて[/h2]
HktkNban氏のHololive JP Mod、Neox氏のHololive EN/ID Modと混ぜて使うことを想定しているため、バニラの指導者より強め(オーバーパワー)の調整にしています。

[h2]⚠️ 注意事項[/h2]
沙花叉クロヱの固有区域・固有建造物は「嵐の訪れ」のルールセットでのみ有効です(それ以外のルールセットでは、文明能力・指導者能力のみ)。
