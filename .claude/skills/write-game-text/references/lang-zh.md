# 中国語(簡体字zh_Hans_CN/繁体字zh_Hant_HK)の規則

`write-game-text` Skillの手順3(他言語に展開する)で中国語を書くときに使う、中国語固有の規則。言語に関係ない手順・規則はSKILL.md本体にあり、ここでは繰り返さない。公式用語の確認は`.claude/rules/game-terms.md`(簡体字と繁体字で語彙自体が違うことがあるので、両方を必ず個別に確認する。下記1節)。ファイル構成・modinfo登録は`add-language`Skillの範囲。

一条莉々華Mod(civ6mod-hololive-regloss)の中国語(簡体字/繁体字)対応で確立した。詳細な調査結果は`official-zh-text-style.md`(2026-09-22、Civ6公式のTrait説明文198件をen_US/zh_Hans_CN/zh_Hant_HK対訳で解析)。以下の節(1〜3節)の個別事例に加えて、コーパス全体では次の傾向が確認できている: 記号は全角が基本だが**パーセント記号`%`だけ半角**、引用符は簡体字がカーブ引用符`" "`・繁体字が鉤括弧「」で件数もほぼ一致、**二人称は簡体字が「您」・繁体字が「你」を標準とする**。
## 1. 同じ文字体系でも地域で語彙自体が違うことがある(要注意)

簡体字/繁体字は字体(文字の形)だけの違いではなく、**同じ概念に別の単語を使っているケースが実在する**。2026-09-22、独占/大企業モードの語彙で確認:

| 概念 | 簡体字(zh_Hans_CN) | 繁体字(zh_Hant_HK) |
|---|---|---|
| Corporation(改善) | 公司 | 企業 |
| Industry(改善) | 行业 | 工業 |
| Monopoly | 垄断 | 獨佔 |
| Warmonger | 好战者 | 好戰份子 |

一方、Yield名(金币/金幣、文化值/文化值等)や建造物名(市场/市場等)は字体変換だけで済むケースも多い。**「同じ言語系統だから片方を機械変換すればもう片方も正しい」と思い込まず、語ごとに実機ファイルで両方を確認すること。**

確認は`tools/loc-lookup`(`npm run lookup`)で両言語をまとめて引く。例: `LOC_GREAT_WORK_OBJECT_RELIC_NAME`(遺物)は簡体字「遗物」・繁体字「遺跡」で、字体変換では出てこない(2026-09-27確認)。

## 2. 句読点・引用符も地域の実機データで確認する

自分の直感(や日本語の感覚)で句読点を選ばない。2026-09-22、簡体字/繁体字で以下の違いを実機ファイルで確認:

- 読点: 両方とも全角(`，`)が標準。半角`,`をそのまま使わない
- 引用符: 簡体字はカーブ引用符`" "`、繁体字は鉤括弧`「」`(日本語と同じ見た目だが独立に確認する)

確認方法: `grep -c "「" Vanilla_zh_Hant_HK.xml`のように候補の記号を実機ファイルで数えて多数派を採用する。

## 3. 簡体字→繁体字の機械変換ツールを使う場合の注意

`opencc-js`(npm)等で簡体字原稿を繁体字へ一次変換すると、字体変換と一部の一般語彙変換はできるが、**上記1節のようなゲーム固有語の語彙差までは変換されない**(ツールはCiv6の用語集を知らない)。機械変換後は必ず1-2節の確認結果で手動パッチすること。

**既知の変換バグ(2026-09-22、opencc-js `cn2hk`で確認)**: 「言う/说」の変換が正しい繁体字「說」ではなく日本語の字体「説」になることがある。機械変換の出力をそのまま信用せず、疑わしい常用字は実機の`Vanilla_zh_Hant_HK.xml`で正しい字形をgrep確認すること。

## 4. UD(固有区域)・UB(固有建造物)のDescription(2026-09-27、実機で確認済み)

規則(置き換え元との差分だけ書く等)はSKILL.md本体。中国語の言い回し:

- **UD**: 簡体字は「[文明]特色区域，代替[置換元]」「[文明]特色区域。替代[置換元]区域」(「代替」「替代」とも実在)、繁体字は「[文明]特色區域。取代[置換元]」で始める。設置の制限は簡体字「无法建在拥有“[区域]”的城市中。无法建在礁石上。」、繁体字「無法建造在擁有「[区域]」的城市中。無法建造在礁石單元格上。」(`LOC_DISTRICT_WATER_STREET_CARNIVAL_EXPANSION2_DESCRIPTION`)。引用符は2節どおり簡体字`“ ”`・繁体字「」で、区域名を囲む
- **UB**: 簡体字「[文明]特色建筑。」、繁体字「[文明]特色建築。」で始める(「取代[置換元]」は原則書かない)
  - `LOC_BUILDING_MADRASA_DESCRIPTION`: 簡体字「阿拉伯特色建筑。提供与学院区的相邻加成等量的 [ICON_Faith] 信仰值。」/繁体字「阿拉伯特色建築。 [ICON_Faith] 信仰值和學院區域的鄰接地域加成相等。」
  - 傑作スロット: 女王の図書館(簡体字「该建筑包含2个槽位，可放置…」、繁体字「此建築提供2個…的槽位。」)
