# 中国語(簡体字/繁体字)ゲーム内テキストのスタイルガイド(公式テキスト調査)

2026-09-22、Civ6公式(バニラ+DLC全種+拡張2本)の文明/指導者Trait説明文198件をen_US/zh_Hans_CN/zh_Hant_HKの3言語対訳で抽出し調査した結果。`SKILL.md`本体の内容(独占/大企業モードの語彙差調査などModの実装作業中に確認した個別事例)を補強する、公式コーパス全体の統計的裏付け。調査方法はNode.jsスクリプトによる抽出(`write-official-en-text-style/references/official-en-text-style.md`の「調査方法」節と同じ手順・同じデータソース)。

## 発見1: 全角原則の中で「%」だけ例外的に半角

読点・句点・コロン・丸括弧は簡体字・繁体字とも**100%全角**(調査した198件で半角の出現は0件):

| 記号 | 簡体字 全角/半角 | 繁体字 全角/半角 |
|---|---:|---:|
| 読点(，/,) | 175 / 0 | 186 / 0 |
| 句点(。/.) | 464 / 0 | 466 / 0 |
| コロン(：/:) | 41 / 0 | 42 / 0 |
| 丸括弧((（/() | 39 / 0 | 31 / 0 |

一方、**パーセント記号だけは半角`%`が標準**(簡体字86件・繁体字81件、全角`％`は0件)。「全角原則」を機械的に全記号へ適用すると`%`だけ誤ることになるので注意。

## 発見2: 引用符は簡体字＝カーブ引用符、繁体字＝鉤括弧で完全に分かれる

簡体字はカーブ引用符`" "`のみ(198件中およそ61件の固有名詞に使用、鉤括弧「」の出現は0件)。繁体字は鉤括弧「」のみ(およそ63件、カーブ引用符の出現は0件)。件数がほぼ一致することから、**同じカテゴリの固有名詞(技術・社会制度・政策・建造物・固有ユニット名など)を、簡体字はカーブ引用符で、繁体字は鉤括弧で、同程度の頻度で囲んでいる**と分かる。日本語の鉤括弧「」が対象とする「トリガーとして言及される固有名詞」の範囲(`write-official-jp-text-style`参照)とほぼ同じ発想。実例:

- 簡体字: `解锁"重商主义"后（而非"民族主义"和"动员"）即可组建舰队和无敌舰队。`
- 繁体字: `獲得「重商主義」後能夠建立艦隊和無敵艦隊，而不需要「民族主義」與「調動」。`

## 発見3: 数字の前にスペースを入れない、アイコンタグの直後はスペース1つが基本

前接する漢字と`+N`/`-N%`の間にスペースは無い(簡体字254件・繁体字263件、実例: `位+1`、`供+1`、`则+15%`)。アイコンタグ`[ICON_XXX]`の直後は半角スペース1つが基本形(簡体字・繁体字とも465箇所中405箇所前後がこの形)だが、約13%はスペース無しのケースもあり、公式データにも一定のブレがある(英語調査でも同種のtypoを確認済み、`write-official-en-text-style`参照)。新規テキストでは「アイコン直後は半角スペース1つ、数字の前にはスペース無し」を基本ルールとして守れば十分。

## 発見4: 簡体字は「您」、繁体字は「你」が標準(新発見、要準拠)

同じ198件の説明文ペアで二人称代名詞の使用頻度を集計したところ、**簡体字は敬称「您」が標準(您15件 対 你1件)、繁体字は「你」が標準(你24件 対 您2件)**という、地域間で完全に逆転した傾向が確認できた。日本語の常体/敬体のような文体差に相当する、簡体字/繁体字間の系統的な違いとして扱ってよい。**新規テキストを書くときは、簡体字では「您」、繁体字では「你」をデフォルトの二人称として使うこと。**

## 発見5: 倍数表現は厳密なルールが無い(用例に頼る)

「2倍」は簡体字・繁体字とも慣用表現の`双倍`/`雙倍`または`加倍`で表現され、「2倍」のようにアラビア数字+倍とはしない。一方「3倍」は同じ簡体字コーパス内でも`3倍`(アラビア数字)と`三倍`(漢数字)の両方が混在しており、**厳密な使い分けルールは無い**。倍数表現を書く際は、この節のような「ルール化できない」事実を踏まえ、近い効果の公式テキストをそのまま参考にすること(独自ルールを作らない)。

## 発見6: 顿号(、)は存在するが読点(，)ほど多くない

列挙表現に使う顿号`、`は簡体字91件・繁体字62件確認できたが、全角読点`，`(175件・186件)の方が明らかに多い。**顿号と読点の使い分けについて明確な規則は今回の調査では見つからなかった**。列挙が必要な新規テキストでは、まず読点`，`を既定にしつつ、似た構造の公式文を探して倣うこと。

## 発見7: 文末はほぼ例外なく句点

簡体字198件中197件、繁体字198件中198件が句点`。`で終わる。日本語・英語と同様、文末記号の省略はほぼ無い。

## 実務ルール(このMod系列で中国語のテキストを書くときに従うこと、SKILL.md本体の内容に追加)

1. 記号は全角が基本だが、**パーセント記号`%`だけは半角**
2. 固有名詞の引用符は**簡体字がカーブ引用符`" "`、繁体字が鉤括弧「」**(SKILL.md 2節の語彙差調査と合わせて、記号自体もこの通り作り分けること)
3. 数字の前にスペースを入れない、アイコンタグの直後は半角スペース1つ
4. **二人称は簡体字「您」・繁体字「你」をデフォルトにする**(新発見。今後この方針で運用し、違和感が出たら見直す)
5. 倍数表現・顿号と読点の使い分けは厳密なルールが無いので、似た効果の公式文をそのまま参考にする(発見5・6)

## 未検証の範囲

調査対象はTrait説明文(198件)のみで、Civilopedia・ユニット/建造物説明文等の他のテキスト種別で同じ規則を直接検証したわけではない。発見4(您/你の使い分け)は特に新しい知見でこのMod内での運用実績がまだ無いため、実際に書いてみて違和感があれば早めに見直すこと。

**発見4の適用範囲について(2026-09-22、既存テキスト監査で確認)**: このMod内でTrait `_DESCRIPTION`等の効果テキストは二人称を一切使わないため、発見4のルールが実際に適用される箇所が無い。二人称が出現するのは外交台詞(`LOC_DIPLO_*`)のみだが、これは`implement-diplomacy-statements`スキルの管轄でキャラクター性格ベースの台詞(本スキルのスコープ外)。一条莉莉华の外交台詞は簡体字・繁体字とも一貫して「你」を使っており(簡体字側に「您」は0件)、本人確認の結果**意図的な選択として現状維持**と決定(フレンドリーな口調のキャラクター性に「你」が合うため)。今後同キャラクターの外交台詞を追加するときも「你」で統一してよい。
