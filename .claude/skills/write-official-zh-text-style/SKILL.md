# Civ6公式スタイルの中国語ゲーム内テキストを書く

一条莉々華Mod(civ6mod-hololive-regloss)の中国語(簡体字/繁体字)対応で確立した、語彙・句読点・機械変換ツールの注意点をまとめたガイド。ファイル構成・modinfo登録は`add-language`Skillの範囲。新規テキストを何をもとに組み立てるか(XML効果定義かキャラクター性か)の判断は`add-language`Skillの「テキストの翻訳元を決める」節を参照。

ゲーム固有の用語を書く前に、`idea`リポジトリの`用語対訳/<ゲーム名>-用語対訳.csv`(`map-terms`Skill管轄、このリポジトリの外)に簡体字名/繁體字名の列が無いか確認する。同CSVは元々日本語版向けの構成なので、その列が無ければ本人に許可を得てから追加する(`add-language`Skill 3節参照)。既存語彙差(1節の表)のような実機確認結果もCSVに追記して再利用する。

新しいテキストを中国語で書く前に、`references/official-zh-text-style.md`も読むこと。2026-09-22、Civ6公式のTrait説明文198件をen_US/zh_Hans_CN/zh_Hant_HK対訳で解析した結果、以下の節(1〜3節)の個別事例に加えて次のようなコーパス全体の傾向が確認できている: 記号は全角が基本だが**パーセント記号`%`だけ半角**、引用符は簡体字がカーブ引用符`" "`・繁体字が鉤括弧「」で件数もほぼ一致、**二人称は簡体字が「您」・繁体字が「你」を標準とする**(新発見)。詳細は同referenceを参照。

## 1. 同じ文字体系でも地域で語彙自体が違うことがある(要注意)

簡体字/繁体字は字体(文字の形)だけの違いではなく、**同じ概念に別の単語を使っているケースが実在する**。2026-09-22、独占/大企業モードの語彙で確認:

| 概念 | 簡体字(zh_Hans_CN) | 繁体字(zh_Hant_HK) |
|---|---|---|
| Corporation(改善) | 公司 | 企業 |
| Industry(改善) | 行业 | 工業 |
| Monopoly | 垄断 | 獨佔 |
| Warmonger | 好战者 | 好戰份子 |

一方、Yield名(金币/金幣、文化值/文化值等)や建造物名(市场/市場等)は字体変換だけで済むケースも多い。**「同じ言語系統だから片方を機械変換すればもう片方も正しい」と思い込まず、語ごとに実機ファイルで両方を確認すること。**

確認先は`add-language`Skillの用語確認手順(`Vanilla_zh_Hans_CN.xml`/`Vanilla_zh_Hant_HK.xml`、各DLCの統合テキストファイル)と同じ。

## 2. 句読点・引用符も地域の実機データで確認する

自分の直感(や日本語の感覚)で句読点を選ばない。2026-09-22、簡体字/繁体字で以下の違いを実機ファイルで確認:

- 読点: 両方とも全角(`，`)が標準。半角`,`をそのまま使わない
- 引用符: 簡体字はカーブ引用符`" "`、繁体字は鉤括弧`「」`(日本語と同じ見た目だが独立に確認する)

確認方法: `grep -c "「" Vanilla_zh_Hant_HK.xml`のように候補の記号を実機ファイルで数えて多数派を採用する。

## 3. 簡体字→繁体字の機械変換ツールを使う場合の注意

`opencc-js`(npm)等で簡体字原稿を繁体字へ一次変換すると、字体変換と一部の一般語彙変換はできるが、**上記1節のようなゲーム固有語の語彙差までは変換されない**(ツールはCiv6の用語集を知らない)。機械変換後は必ず1-2節の確認結果で手動パッチすること。

**既知の変換バグ(2026-09-22、opencc-js `cn2hk`で確認)**: 「言う/说」の変換が正しい繁体字「說」ではなく日本語の字体「説」になることがある。機械変換の出力をそのまま信用せず、疑わしい常用字は実機の`Vanilla_zh_Hant_HK.xml`で正しい字形をgrep確認すること。
